## Projects

### [Order & Inventory Management System — Full Systems Analysis](order-inventory-system-analysis/) *(team project)*
A complete structured-analysis package for an order and inventory management system:

- **Process modelling** — context diagram, zero-level DFD, child diagrams for purchasing and
  transaction tracking
- **Data modelling** — entity-relationship diagrams for the product and order databases
- **Data dictionaries** — full data-flow and data-store definitions
- **Project planning** — work breakdown structure, Gantt chart, and PERT network in Microsoft
  Project, with a re-baselined schedule showing the impact of adding the analysis phase
- **Requirements** — project charter and stakeholder questionnaire
- **Interface design** — UI screens in Adobe XD
- **Delivery** — two stakeholder presentations and a final report

`Structured analysis` `Microsoft Visio` `Microsoft Project` `Adobe XD`

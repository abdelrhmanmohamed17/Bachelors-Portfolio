# 07 — Intelligent Systems & Optimization

Search and optimization approaches that don't rely on gradients: evolutionary algorithms, emergent
rule-based systems, and classical operations research.

---

## Projects

### [Genetic Algorithm Optimizer](genetic-algorithm-optimizer/)
Selection, crossover, and mutation operators implemented from scratch to solve an optimization
problem through evolutionary search — useful precisely where the objective function isn't
differentiable.

`Python` `NumPy`

### [Cellular Automata Simulation](cellular-automata-simulation/)
A rule-based cellular automaton with generation-over-generation state visualization, demonstrating
how complex global behaviour emerges from purely local rules.

`NumPy` `Matplotlib`

### [Operations Research Problem Sets](operations-research-problems/)
Constrained-optimization and resource-allocation problems across multiple assignment sets: linear
programming, transportation and assignment problems, and network optimisation.

`Linear programming` `Optimization`

---

## Skills Demonstrated

- Evolutionary algorithm design: fitness functions, selection pressure, crossover, mutation rates
- Emergent-behaviour modelling with local update rules
- Linear programming formulation and solution
- Constrained optimization and resource allocation
- Choosing between gradient-based and gradient-free methods based on problem structure

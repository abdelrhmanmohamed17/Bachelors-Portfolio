# 10 — Coursework & Assignments

Problem sets, written assignments, and supporting course material that don't constitute standalone
projects but document the breadth of the degree.

---

## Contents

### Neural Networks — Assignment Series
Four graded sheets plus two assignments covering perceptrons, backpropagation by hand, activation
functions, and network topology design.

### AI Platforms & Frameworks — Assignment Series
Notebook assignments working through TensorFlow and PyTorch fundamentals, dataflow graphs,
abstractions, tokenization, embeddings, and LSTM implementations.

### Natural Language Processing — Assignment Series
Three assignments covering Python fundamentals, regular expressions and entity extraction, and a
comparison of logistic regression against Naive Bayes for text classification.

### Intelligent Technology Trends — Written Assignments
Five written assignments surveying emerging technology directions.

### Operations Research — Problem Sets
Linear programming and optimization problem sets with worked solutions.

### Game Theory — Quiz
Strategic-interaction problems and equilibrium analysis.

### Field Training — SAS Data Analytics
An investigation-phase report and final analysis on the Ames Housing dataset using SAS, produced
during a data analytics field training placement.

### Continuing Education
- Deep Learning specialisation: logistic regression with a neural network mindset, implementing
  sigmoid, parameter initialisation, forward/backward propagation, and gradient descent from
  scratch
- CS50P — Introduction to Programming with Python (Harvard)

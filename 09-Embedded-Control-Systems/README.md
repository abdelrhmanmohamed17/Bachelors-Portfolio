# 09 — Embedded & Control Systems

Hardware projects and control theory — where the model has to work against physics rather than a
dataset.

---

## Projects

### [Critical Distance Detection System](critical-distance-detection/)
An ultrasonic proximity-detection system that triggers an alert when an object crosses a
configurable critical distance. Documented with a full circuit schematic and a demonstration video.

`Arduino` `C++` `HC-SR04 ultrasonic sensor`

### [Control Systems Laboratory Series](matlab-control-systems-labs/)
Modelling and analysis of control systems including a ball-and-beam plant: transfer-function
derivation, root-locus analysis, and zero-order-hold discretization for digital implementation.

`MATLAB`

---

## Skills Demonstrated

- Microcontroller programming and sensor interfacing
- Time-of-flight distance measurement and threshold logic
- Circuit design and schematic documentation
- Transfer-function derivation from physical plant models
- Root-locus and stability analysis
- Continuous-to-discrete conversion (zero-order hold) for digital control
